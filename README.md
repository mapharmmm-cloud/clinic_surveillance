<h1 align="center">ระบบเฝ้าระวังมาตรฐานสถานพยาบาล</h1>
<p align="center">งานคุ้มครองผู้บริโภค โรงพยาบาลกุมภวาปี</p>

Web Application สำหรับบันทึก ประมวลผล และแสดงผลการตรวจมาตรฐานสถานพยาบาลประเภทคลินิก (การตรวจเฝ้าระวังประจำปี) ครอบคลุมแบบบันทึก 10 ประเภท:

คลินิกเวชกรรม · คลินิกเฉพาะทางด้านเวชกรรม · คลินิกทันตกรรม · คลินิกการพยาบาลและการผดุงครรภ์ · การแพทย์แผนไทย (ประยุกต์ / เวชกรรมไทย / นวดไทย) · คลินิกเฉพาะทางเวชกรรม สาขาไตเทียม · คลินิกเทคนิคการแพทย์ · คลินิกการแพทย์แผนจีน

## ความสามารถ
- **บันทึกการตรวจ** แบ่งขั้นตอนตามแบบบันทึกต้นฉบับ ผลการตรวจรายข้อ ✓ / × / – พร้อมหมายเหตุ และตรวจสอบความครบถ้วนก่อนบันทึก
- **ลงลายมือชื่อบนหน้าจอ** ด้วยนิ้ว ปากกา หรือเมาส์
- **บันทึก PDF** ในรูปแบบเดียวกับแบบบันทึกต้นฉบับ
- **Dashboard สาธารณะ** แสดงเฉพาะข้อมูลสรุปที่ไม่ระบุตัวตน
- **ระบบผู้ดูแล** ค้นหา แก้ไข ลบ ดูประวัติการแก้ไข และส่งออก Excel / CSV / JSON
- รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

## การใช้งาน
เปิดผ่าน GitHub Pages ของ repository นี้ หรือดาวน์โหลด `index.html` แล้วเปิดด้วยเบราว์เซอร์

ระบบจัดเก็บข้อมูลใน Google Sheets ผ่าน Google Apps Script

## ข้อมูลส่วนบุคคล
- Repository นี้ไม่มีข้อมูลการตรวจหรือข้อมูลส่วนบุคคลใด ๆ ข้อมูลทั้งหมดอยู่ใน Google Sheets ที่จำกัดสิทธิ์การเข้าถึง
- Dashboard สาธารณะไม่แสดงชื่อสถานพยาบาล ชื่อบุคคล เลขใบอนุญาต หมายเลขโทรศัพท์ ที่อยู่ละเอียด หรือลายมือชื่อ
- การดูข้อมูลรายรายการ การแก้ไข และการลบ ต้องเข้าสู่ระบบผู้ดูแล
